## 📖 About The Project

**Nexa Development** is a modern, responsive website for a web and app development studio. It showcases how we build websites and web applications that help businesses establish a strong digital presence, from landing pages to custom web solutions, turning ideas into functional digital experiences.

### ✨ Key Features

- 📱 **Fully Responsive:** Looks great on mobile, tablet and desktop.
- 🎨 **Modern UI/UX:** Clean, dark-themed design with smooth sections and layout.
- 🧩 **Services Showcase:** Presents web, app and custom development solutions.
- ⚡ **Fast & Lightweight:** Optimized for quick loading and smooth browsing.
- 📬 **Easy to Reach:** Clear way for clients to get in touch.

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

- Node.js (v16+)
- npm

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/maheennadeem567-sys/Nexa-development.git

# 2. Go to the project folder
cd Nexa-development

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

---

## 🌐 Deployment

This project is deployed on **Netlify**.

1. Connect your GitHub repository to Netlify.
2. Set the build command to `npm run build`.
3. Set the publish directory to `dist`.
4. Deploy!
